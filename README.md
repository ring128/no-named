## 内容

ゴールへ向かうNPCを、能力を使って妨害するブラウザゲームです。
まずは1ステージ・1 NPC・1種類の能力で遊べる状態を目指します。

## 技術構成

### フロントエンド

- TypeScript
- Vite
- HTML・CSS
- Canvas API（ゲーム画面の描画に使用予定）

### バックエンド

- C++20
- CMake（ビルド用）
- Drogon（HTTP通信に導入予定）

### 今後導入を検討

- PostgreSQL：ユーザー情報・挑戦記録・ランキングの保存
- WebSocket：協力プレイ時の状態同期

## 現在の進捗

Viteの初期画面を起動できる状態です。
C++側はCMakeの設定を始めた段階で、ゲーム本体はまだ実装していません。
